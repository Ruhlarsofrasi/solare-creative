# Media

Put project films, posters and stills here, then reference them from`src/content/projects.ts` as `/media/<file>`.

- Film: H.264 MP4, 1080p, ideally under ~25 MB (or use an external CDN URL).
- Billboard preview (optional `previewVideo`): short muted loop, 720p, under ~4 MB.
- Poster: JPG/WebP, ~1600 px wide.
